# 🌤️ WeatherAI — Интеллектуальная метеоплатформа будущего

**WeatherAI** — это передовое веб-приложение для отслеживания погоды, которое объединяет высочайшую точность метеорологических сервисов с аналитической мощью искусственного интеллекта. Проект создан для обеспечения вашего максимального комфорта при планировании дня, поездок и активностей.

## ✨ Ключевые возможности

- 🎯 **Высокоточный прогноз погоды** — Детальная информация о текущей погоде, почасовой прогноз на 24 часа и подробный обзор на 7 дней вперёд: температура, влажность, ветер, давление, видимость, УФ-индекс и восход/закат.

- 🤖 **Продвинутый ИИ-ассистент (Claude AI)**
  - **Умный чат:** Задавайте вопросы голосом или текстом. ИИ самостоятельно анализирует запрос и извлекает актуальные данные о погоде для любого упомянутого города в реальном времени.
  - **Быстрые подсказки (Quick Prompts):** Готовые сценарии — советы по одежде, активностям, планированию поездок — в один клик.
  - **Голосовой ввод:** Поддержка Web Speech API для голосовых запросов.
  - **ИИ-гороскоп:** Страница гороскопов с персонализированными астрологическими прогнозами, сгенерированными ИИ.

- 🌍 **Мониторинг городов Казахстана и Мира** — Выделенная страница с синхронным мониторингом погоды по регионам: все областные центры РК, а также города СНГ, Европы, Азии, Ближнего Востока, Северной и Южной Америки, Африки и Океании — с фильтрацией и поиском.

- 🗺️ **Интерактивная метеокарта** — Две карты на отдельных страницах:
  - **Основная карта** (`map.html`): слои осадков, снега, ветра, температуры и облачности в реальном времени через RainViewer и OpenWeatherMap.
  - **Мировая карта** (`map-world.html`): глобальная визуализация погодных данных по всему миру с маркерами городов.

- 🌙 **Лунный календарь** — Отдельная страница с астрономическими расчётами: фаза луны, процент освещённости, лунные сутки, восход и заход луны. Динамические рекомендации для садоводства, здоровья и бизнеса. Полностью переведена на три языка.

- ♈ **Гороскоп** — Отдельная страница с ИИ-прогнозами для всех знаков зодиака с поддержкой мультиязычности.

- 📖 **Интерактивное руководство** — Встроенная справка (Info Modal), описывающая все ключевые функции приложения: от сравнения городов и экспорта до мини-календаря и работы с картой.

- 📊 **Конструктор экспорта данных** — Гибкий экспорт погодной истории и прогнозов с настройкой периода, параметров (температура, влажность, ветер, осадки, давление, УФ, видимость, восход) и формата: **JSON, CSV, Excel (XLSX)**.

- 📲 **Telegram-бот** — Кроссплатформенный доступ к прогнозам прямо в мессенджере: [@WeatherAI_v2_bot](https://t.me/WeatherAI_v2_bot).

- 🌗 **Персонализация и локализация** — Поддержка трёх языков (🇷🇺 RU, 🇰🇿 KK, 🇬🇧 EN) на всех страницах. Автоматическая светлая/тёмная тема. Геолокация для мгновенного определения вашего города.

- 📅 **Мини-календарь** — Встроенный интерактивный виджет в шапке сайта для быстрой навигации по датам.

- ℹ️ **Страницы проекта** — Полноценные страницы «О проекте» (`about.html`) и «Контакты» (`contact.html`), а также политика конфиденциальности (`privacy.html`).

## 🛠 Технологический стек

Проект построен на чистых веб-технологиях без тяжёлых фреймворков — для максимальной скорости и лёгкости:

- **Ядро:** HTML5, Vanilla JavaScript (ES6+), Web Speech API
- **Стилизация:** CSS3 (Flexbox, Grid, CSS-переменные, модульная архитектура)
- **Интеграции (APIs):**
  - [Open-Meteo](https://open-meteo.com/) — бесплатный высокоточный источник метеоданных
  - [OpenWeatherMap](https://openweathermap.org/) — геокодирование, обратный поиск, погодные тайлы для карты
  - [RainViewer](https://www.rainviewer.com/) — радарные данные и слои осадков
  - [Anthropic Claude API](https://www.anthropic.com/) — ИИ-ядро чата и генерации гороскопов
- **Библиотеки:**
  - [Chart.js](https://www.chartjs.org/) — графики температурных трендов
  - [Leaflet](https://leafletjs.com/) — движок интерактивных карт
  - [Lucide Icons](https://lucide.dev/) — современная SVG-иконография
  - [SheetJS (xlsx)](https://sheetjs.com/) — экспорт в формат Excel

## 🏁 Быстрый старт

Проект является статическим веб-приложением (Static Web App) — бэкенд и база данных не требуются:

1. Склонируйте репозиторий или скачайте исходный код.
2. Запустите `index.html` через локальный веб-сервер.
   > 💡 Рекомендуется расширение **Live Server** для VS Code — оно решает ограничения браузера (CORS) при загрузке локальных JSON-файлов переводов.
3. Для полноценной работы ИИ-чата и гороскопов укажите свой ключ Anthropic API в соответствующем модуле.
4. Для отображения погодных слоёв на карте укажите ключ OpenWeatherMap в `js/map-world.js`.
